# 分类-每日巡检 Bug

**归档范围**：通过**日常巡检 / 定期回归 / 抽查**发现的 Bug。

## 适用场景

- 每次发版 / 重构后的例行回归检查；
- 跨浏览器、跨分辨率、不同数据量 / 边界数据抽查；
- 偶发、难以稳定复现的问题（先记录现象与观察时序，标注「待复现」）。

## 命名规范

`YYYY-MM-DD-巡检-主题.md`，单条 Bug 用 `模板/Bug条目模板.md` 记录。
