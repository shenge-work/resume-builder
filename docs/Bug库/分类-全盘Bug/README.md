# 分类-全盘 Bug

**归档范围**：**跨功能 / 全局性** Bug——布局、路由、数据层、面板交互、性能、兼容性等底座问题，多个功能共同受影响。

## 判定规则

- 影响面超过单个模块（如平板布局溢出导致所有配置面板不可达、工具菜单互斥影响编辑与导出、控制台报错干扰排障、数据丢失风险）→ 归此类。
- 只影响单个模块的问题 → 归 `分类-独立需求Bug`。

## 命名规范

`YYYY-MM-DD-主题.md`；整轮全功能测试清单可直接整体归档（一个文件含多条 Bug）。
