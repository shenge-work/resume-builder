# 分类-独立需求 Bug

**归档范围**：只影响**单个需求 / 单个功能模块**的 Bug（其他功能不受牵连）。

## 判定规则

- 问题局限在一个模块内（如「JD 匹配分析」「投递追踪」「导出 Word」「编辑器·基本信息」）→ 归此类。
- 若问题同时影响多个功能、或涉及布局 / 路由 / 数据层 / 面板交互底座 → 归 `分类-全盘Bug`。

## 命名规范

`YYYY-MM-DD-主题.md`，单条 Bug 用 `模板/Bug条目模板.md` 记录。
