# Bug 条目模板

> 单条 Bug 独立记录时使用本模板；整轮测试清单归档时可合并多条（见 `分类-全盘Bug/功能测试-Bug清单.md` 的段落结构）。
> 复制本文件到对应分类目录，按 `YYYY-MM-DD-主题.md` 命名，并填写以下字段。

---

## 基本信息

| 字段 | 内容 |
|---|---|
| Bug 编号 | BUG-XX（按发现顺序递增，跨分类全局唯一） |
| 标题 | 一句话概括（现象 + 对象） |
| 严重程度 | P0=功能完全不可用/数据风险；P1=主要功能受影响；P2=体验缺陷；P3=轻微问题 |
| 状态 | 待修复 / 修复中 / 已修复待验证 / 已关闭 / 待复现 |
| 发现日期 | YYYY-MM-DD |
| 涉及模块 | 所属需求 / 功能 / 文件 |
| 关联需求 | （如有）需求编号或需求文档链接 |
| 发现来源 | 独立需求测试 / 全盘测试 / 每日巡检 / 用户反馈 |

---
