## 一、背景与竞品参照

**Reactive Resume 的 AI Agent 工作区**是同类开源项目里最完整的 AI 落地形态：

1. **AI 代理在聊天中编辑简历**——不是简单生成一段文字，而是理解简历上下文后产出结构化修改；
2. **补丁式编辑 + Diff 展示**——AI 的修改以 patch diff 卡片呈现，可展开查看逐条操作；
3. **人工审批步骤（human-approval）**——AI 的编辑需经人工批准后才生效；
4. **撤销/回滚（Revert）**——已应用的 AI 修改可一键回滚，并正确提示版本冲突；
5. **多供应商接入**——OpenAI / Gemini / Claude / DeepSeek。

**magic-resume** 印证了中文场景对国产模型（DeepSeek/Qwen/豆包）的亲和。**Magic Resume**（magic-resume 升级版）进一步提出「AI 在实处提出编辑，用户逐条接受/跳过（accept or skip）」的交互，与本需求的 Diff 审阅卡片一致。

**本项目现状**：`docs/AI能力/AI辅助写简历-技术设计方案.md` 已定 DeepSeek v4 + `tools/ai-proxy.js` 中转（LLM 禁浏览器直连，CORS）；评估文档已把「AI 阶段 2」列为 P2 #11；`js/ai/` 目录已预留（scope/prompts/diff/apply），阶段 1 基建（`tools/ai-proxy.js` SSE + `/api/ai` + `js/ai/{presets,provider,ui/panel}.js`）已完成。**阶段 2 核心闭环尚未落地**。

## 三、需求描述

### 3.1 核心闭环（五步）

```
选中文本/板块 → 触发润色 → AI 生成 → Diff 审阅卡片 → 应用或撤销
```

### 3.2 功能点

**F1 作用范围显式**：用户先选中一段经历/一个板块，再触发 AI，AI 只对选中范围产出修改，不得越界改其他内容。

**F2 润色动作**：提供「润色 / 扩写 / 精简 / 改 STAR 结构 / 匹配 JD 关键词」等动作入口。

**F3 Diff 审阅卡片**：AI 返回的修改以**逐条 diff**（原文 → 新文，增删高亮）展示，用户逐条勾选接受/拒绝；不整段替换。

**F4 人工审批门控**：默认 AI 修改不直接写入简历，需用户点击「应用」才落盘。

**F5 撤销/回滚**：已应用的单条/整批修改进撤销栈，可一键回滚；回滚时若目标段落已被用户二次编辑，提示版本冲突。

**F6 事实护栏（guard）**：拦截 AI 编造的数字、公司名、时间段——凡与原文不一致的硬事实（数字/公司/日期）高亮警示，须用户手动确认才放行。

**F7 可脱敏**：发送前可一键把姓名/电话/邮箱/公司名替换为占位符，审阅后再还原。

**F8 模型配置**：设置页配置 API Key（存 gitignored `ai.config.json`），支持 DeepSeek 及后续国产模型切换。

### 3.3 交互细节

- 选中文本后浮现浮动工具条（润色按钮），无选中态时按钮置灰。
- Diff 卡片逐条带「接受 / 拒绝」按钮，底部「全部接受 / 全部拒绝」。
- 生成中显示 loading 态，可取消；失败可重试，错误信息明确（网络/CORS/Key 无效/配额）。
- 事实护栏命中的字段在 diff 卡片里用醒目样式标出，接受前需二次确认。

## 四、数据结构

- 按已定设计：`js/ai/scope.js`（作用范围）+ `prompts.js` + `diff.js` + `apply.js` + Diff 卡片 UI。
- 模型请求走 `tools/ai-proxy.js`（服务端中转），Key 存 gitignored `ai.config.json`。
- AI 修改应用前不落盘；应用后走 `currentPayload()` + savedAt 正常持久化，并进撤销栈。

---

## 五、验收标准

1. 选中一段经历 → 点润色 → 出 Diff 对比 → 可逐条接受/拒绝 → 应用后内容正确更新。
2. 应用后可撤销；撤销后如目标被二次编辑则提示冲突。
3. 事实护栏：AI 试图改动数字/公司名/日期时，该字段被高亮警示且默认不放行。
4. 脱敏：发送前可替换敏感字段，审阅后还原。
5. 无 Key 时功能入口给出清晰引导，不报错崩溃。
6. AI 越界修改（超出选中范围）被拦截。

## 六、工程护栏

1. **AI 五原则**（`docs/AI能力/AI辅助写简历-技术设计方案.md` 已定）：Diff 审阅 / 范围显式 / 可撤销 / guard 护栏 / 可脱敏——不得绕过。
2. LLM 禁浏览器直连（CORS），必须走 `tools/ai-proxy.js`。
3. `js/ai/` 平行接入，**不拆 app.js**。
4. 新增模块遵守「四处接线」铁律 + 变异测试。
5. Key 绝不进 git，提交前 `git grep` 扫 Key/PII。

## 七、非目标

- **不做**全自动生成整份简历（无人工审批）——始终保留人工门控。
