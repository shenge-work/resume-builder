# N5 简历缩略图仪表盘

> 编号：N5　优先级：P3（评审下调）　借鉴来源：Reactive Resume（dashboard 简历缩略图预览）　状态：待验收（F1/F3 已落地，F2 延后）
> 评审结论：✅ 通过，降为 P3（2026-09-21）

---

## 一、背景与竞品参照

**Reactive Resume** 的仪表盘（dashboard）中，每份简历以**缩略图卡片**呈现，一眼识别哪份是哪份，而非只靠标题文字。

**本项目现状**：简历库左抽屉用「标题 + 徽标（定制版）」文字列表呈现（`renderResumeDrawer`），多份简历时辨识度低——尤其「母简历 vs 多个派生版」血缘关系不直观。

---

## 二、用户价值

| 痛点 | 收益 |
|---|---|
| 简历多了靠标题猜内容 | 缩略图一眼识别版式与内容 |
| 派生版血缘靠文字徽标，不直观 | 缩略图 + 血缘层级可视化 |

---

## 三、需求描述

### 3.1 功能点

**F1 简历缩略图**：简历库卡片生成简历首页的缩略图（基于当前 payload 渲染迷你预览），随内容更新而刷新。

**F2 血缘层级可视化（可选增强）**：母简历卡片下缩进显示其派生版（利用已落地的 `parentId`/`children`），形成「母 → 派生」树形，比平铺列表更直观。

**F3 卡片信息增强**：卡片显示标题、更新时间、定制版徽标、缩略图、标签（tags）。

### 3.2 交互细节

- 缩略图懒加载/缓存，避免多份简历时卡顿（`renderResumeDrawer` 每次全量刷新，需注意性能）。
- 缩略图是**预览用**，不可点击编辑，点击整卡进入该简历。
- 血缘树可折叠/展开。

### 3.3 边界与异常

- 简历为空/新建时显示占位缩略图（空纸张轮廓）。
- 生成缩略图用轻量方式（复用渲染逻辑输出到小尺寸容器，不额外截图依赖）。

---

## 四、数据结构

- 复用现有 `parentId`/`children`，无需新增存储字段。
- 缩略图缓存可用内存态（不落盘），内容变化时失效重建。

---

## 五、验收标准

1. 简历库每份简历显示缩略图，且随内容更新刷新。
2. 派生版在母简历下缩进显示，血缘关系清晰。
3. 空简历显示占位缩略图，不报错。
4. 多份简历时抽屉渲染不卡顿（性能可接受）。

---

## 六、工程护栏

1. `renderResumeDrawer` 全量刷新是既有性能点，缩略图须懒加载/缓存，勿加重每键重渲染。
2. 遵守「四处接线」铁律 + 变异测试。
3. PII 隔离（缩略图即简历内容，测试用虚构数据）。

---

## 七、非目标

- **不做**服务端图片托管/缩略图上传。
- **不做**拖拽调整简历排序（卡片排序可后续与主题板块排序统一，另行立项）。

## 九、实现记录与验收对照（2026-09-21）

**实现要点**
- 新增 `ResumeRender.buildResumeHtml(payload)`（`js/render/resume-render.js`）：把任意简历 payload 渲染成「首页」HTML 字符串，**不改写已稳定多年的渲染层**——采用「临时覆盖全局 `data`/`currentFonts`/`currentSpacing` → 渲染 → `finally` 恢复」的受保护交换；空简历返回 `''`（调用方显示占位纸张）。
- **#/library 卡片网格**（`js/views/library-view.js`）：原「首字母方块」升级为真实迷你预览（`renderThumbs`，按 `id|updatedAt` 内存缓存，内容变化即失效）。卡片改为横向布局：左侧缩略图 + 右侧标题/更新时间/来源/标签，派生版带「定制版」徽标（F3）。
- **左抽屉**（`js/app.js` `renderResumeDrawer` + `renderDrawerThumbs`）：每份简历卡片加缩略图槽；缓存按 `id|updatedAt` 失效，确保「每键重渲染」只命中缓存、仅在真正落盘后重建一次，避免把缩略图生成变成性能黑洞（落实工程护栏 6.1）。
- CSS：`.resume-thumb`（固定 A4 比例容器 + `.resume` 内部 `transform: scale` 贴合）+ `.is-empty` 占位 + 桌面/抽屉两套尺寸。

**验收对照**
| 验收标准 | 结果 |
|---|---|
| 1. 每份简历显示缩略图，随内容更新刷新 | ✅ 缓存键含 `updatedAt`，落盘后失效重建 |
| 2. 派生版在母简历下缩进显示（F2 血缘树） | ⏸ 延后（评审标注「可并入 D3 血缘 UI」，列为可选增强，本次未做） |
| 3. 空简历显示占位缩略图，不报错 | ✅ `buildResumeHtml` 返回 `''` → `.is-empty` 占位「空白简历」 |
| 4. 多份简历时抽屉渲染不卡顿 | ✅ 缓存 + `updatedAt` 失效，编辑中零重建 |

**测试**：`test/cases.js` 加 5 条 `buildResumeHtml` 断言（`.resume` 包裹 / 含姓名 / 含板块标题 / 空 sections 返回空串 / 不改写全局 `data`）；`node test/run.js` 全绿（1001/0）。
