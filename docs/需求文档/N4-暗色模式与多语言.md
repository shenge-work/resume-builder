# N4 暗色模式与界面多语言

> 编号：N4　优先级：P2　借鉴来源：Reactive Resume（暗色模式 / 53 种语言 / PWA）　状态：待开发
> 评审结论：✅ 通过（2026-09-21）　详见文末 §八
>
> ⚠️ **范围澄清**：本文的「多语言」指**界面 chrome（按钮/菜单/提示）的 i18n**，与「简历正文翻译」是两个不同需求——后者见 **[N8 简历内容翻译](./N8-简历内容翻译.md)**。

---

## 一、背景与竞品参照

**Reactive Resume** 的产品级体验细节：

1. **暗色模式**——编辑器 UI 支持深色主题；
2. **多语言**——53 种 locale，完整翻译管线（Crowdin 管理）；
3. **PWA**——可安装为渐进式 Web 应用。

**本项目现状**：界面为浅色；文案为中文硬编码；单文件离线版可视为某种程度的「免安装」，但未做标准 PWA。

---

## 二、用户价值

| 痛点 | 收益 |
|---|---|
| 夜间/弱光环境编辑刺眼 | 暗色模式护眼 |
| 界面文案固定中文 | 多语言（至少中英）扩展用户群 |
| 需登录才能用是负担 | 免安装 PWA，打开即用 |

---

## 三、需求描述

### 3.1 功能点

**F1 暗色模式**：提供「浅色 / 深色 / 跟随系统」三态切换；设置页 + 顶栏快捷切换；选择持久化（localStorage）。

**F2 多语言（中英优先）**：界面文案抽离为 i18n 字典，先覆盖中英双语，语言切换即时生效；预留扩展其他语言。

**F3 PWA（可选）**：manifest + service worker，支持「添加到主屏幕」离线使用（与单文件离线版互补，标准 PWA 可更好地缓存）。

### 3.2 交互细节

- 暗色模式切换**即时生效、无闪烁**（首屏渲染前读 localStorage 避免闪白/闪黑）。
- 简历**预览区**默认不随编辑器暗色模式变暗（简历纸张保持白色，这是印刷品预览的语义）；提供「预览也跟随暗色」的显式开关。
- 语言切换影响**界面 chrome**（菜单/按钮/提示），**不翻译简历内容**（用户简历正文不受影响）。
- 暗色/语言状态存 localStorage，跨会话保持。

### 3.3 边界与异常

- 主题色变量需覆盖所有 UI 组件（抽屉、菜单、浮动面板、保存状态条、设置页）。
- 打印（`@media print`）始终用浅色，暗色不影响导出。

---

## 四、数据结构

- i18n 字典：`js/i18n/`（`zh.js` / `en.js` + `index.js` 门面），文案 key 化。
- 暗色/语言状态：localStorage（`theme_ui_v1` / `lang_v1`）。

---

## 五、验收标准

1. 三态切换即时生效、无闪烁、刷新后保持。
2. 所有 UI 组件在暗色下可读（无「深色文字配深色底」），预览区默认保持白色纸张。
3. 切到英文 → 界面 chrome 全英文、简历正文不变。
4. 打印/导出 PDF 不受暗色影响。
5. 新增文案不再硬编码（代码审查约束）。

---

## 六、工程护栏

1. 文案抽离是**大范围改动**，须分组件渐进迁移，避免一次性全改引入回归。
2. 遵守「四处接线」铁律（新增 i18n 模块）＋ 变异测试。
3. 暗色配色遵守「涨红跌绿」等既有视觉约定；使用 CSS 变量统一管理，禁裸色值散落。

---

## 七、非目标

- **不做** 53 种语言全量翻译，先中英双语，扩展语言留接口。
- **不做**简历内容自动翻译——那是独立需求 [N8 简历内容翻译](./N8-简历内容翻译.md)，需 AI 能力，不在本文范围。
- PWA 为可选增强，不影响核心「单文件离线 HTML」护城河。

---

## 八、评审结论（2026-09-21）

| 评审维度 | 结论 |
|---|---|
| 护城河 | ✅ 守住（纯 UI 改造，不碰渲染/存储核心） |
| 价值 | 中（体验优化，非主线；暗色对夜间编辑是刚需，i18n 对中文用户优先级低） |
| 成本 | 中（文案抽离是大范围改动，需渐进迁移） |
| 依赖 | 暗色模式依赖 N1 的 CSS 变量主题体系 |
| **结论** | **通过，定 P2**；建议「暗色模式」与「i18n」**拆开排期**——暗色先做（刚需、依赖 N1），i18n 后做（低优先） |
