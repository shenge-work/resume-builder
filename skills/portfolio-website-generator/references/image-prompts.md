# 图片生成 · 统一风格提示词与生产流程

网站需要 8~10 张图（不打包在模板里，每次按用户人设现场生成）。全部图片必须共用逐字一致的风格前缀，仅替换主体内容。

## 1. 统一风格前缀（所有 prompt 的开头）

```
新粗野主义风格扁平插画：米白色纯净背景，极粗黑色描边线条，扁平色块，亮橙色和克莱因蓝作为强调色，复古丝网印刷/孔版印刷质感，大胆海报构图，画面中不出现任何文字
```

## 2. 分类提示词模板

### 2.1 个人形象照（1 张，1:1 方图）
```
{风格前缀}。一位 {年龄} 岁的中国{性别}{职业气质描述，如：男大学生/女设计师}半身像，
{发型}，{眼镜/配饰}，穿 {亮橙色系服装}，表情自信略带微笑。
证件照构图居中，角落点缀克莱因蓝几何色块。
```
服装固定橙色系（呼应主强调色）；气质贴合职业（程序员=连帽卫衣、设计师=oversize 衬衫、金融=马甲等）。

### 2.2 项目封面（N 张，16:9 横图）
```
{风格前缀}。{项目主题}：{2~3 个具象物件 + 1 个动感元素}。
```
物件从项目内容反推，如二手书平台=书塔+纸飞机+循环箭头+价格吊牌；书法应用=毛笔+米字格+墨滴+印章；数据大屏=折线图+地图大头针+脉冲环。每个 prompt 的物件数保持 3~4 个，构图密度一致。

### 2.3 证书卡（M 张，约 31:22 横图）
```
新粗野主义风格证书卡片插画：横版{证书类型}设计，米白色纸张底色带细点阵纹理，
四边有黑色粗边框，中央 {核心徽章图形}，{缎带/放射线/橄榄枝装饰}，
扁平色块，极粗黑色描边，简洁庄重又潮流，画面中不出现任何文字。
```
核心图形按证书类型选：语言类=圆形奖章+星徽、职业资格=六边形科技徽章+电路纹理、竞赛类=奖杯+绶带+星星纸屑。主色在橙/蓝/金之间轮换保证视觉区分。

## 3. 并行生成注意事项（重要踩坑）

1. **并行调用的返回顺序与请求顺序不保证一一对应**。4 个并行请求中第 1 个返回的可能是第 2 个 prompt 的图。**必须逐张验证内容后再重命名映射**，禁止按返回顺序直接命名
2. 推荐验证法：PIL 将全部新图拼成网格（每格留缝），用一次视觉理解调用让模型逐格描述核心主体，再对照预期用途重命名
3. 成套风格复查：全部生成后拼网格整体看一遍，风格不统一的单独重生成

## 4. 水印处理

生图服务可能在图片角落附带半透明水印：
- 若水印所在区域为纯背景：用 OpenCV `inpaint`（TELEA 算法）对固定矩形区域全量修复，比阈值检测更可靠（阈值法对自适应深浅的水印会漏检，已踩坑）
- 若水印压在画面主体上：直接重生成该图
- 修复后拼图复查，确认无残留、无拉丝痕迹

## 5. 尺寸与压缩

| 图片 | 生成尺寸 | 落盘尺寸 | JPEG 质量 |
|---|---|---|---|
| 形象照 | 2048×2048 | 1000×1000 | 84 |
| 项目封面 | 2560×1440 | 1280×720 | 84 |
| 证书卡 | 2568×1848 | 1240×892 | 84 |

全部图控制在 350KB 以内（整站 <2.5MB），用 `cv2.resize(INTER_AREA)` 缩放。

## 6. favicon

用 `scripts/make_favicon.py` 从形象照生成（橙底 + 圆形头像黑描边 + 黑底像素字母徽章），字母参数取用户姓氏/名字缩写。生成后必须放大徽章区域人工核对字母形（像素字母 J 的钩在底部，易画成 I）。

引用位置：index.html 与 resume.html 的 `<head>` 中 favicon-64.png / favicon.png / apple-touch-icon。
