# 简历编辑器（Resume Builder）

一个**纯前端、零依赖后端**的简历排版工具：左侧实时预览，右侧纯文本编辑，拖拽调序，一键导出 PDF。

原文件是一份单文件 HTML；本项目把它拆成多文件，便于用 Git 管理与协作。

---

## 快速开始

**方式一：直接用多文件版**

```bash
# 用任意静态服务器打开（推荐，避免 file:// 的限制）
cd resume-builder
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

**方式二：生成单文件版后离线使用**

```bash
node tools/build-single.js
# 产物：dist/简历编辑器-单文件.html  → 可直接双击打开、断网可用
```

> 直接双击 `index.html`（`file://`）大多也能正常工作；若遇到 PDF 导出异常，改用方式一的本地服务器即可。

## 目录结构

```
resume-builder/
├── index.html              # 页面骨架
├── css/
│   └── style.css           # 全部样式
├── js/
│   ├── data.js             # ★ 简历数据 + 默认字号/间距（唯一数据源，改内容就改这里）
│   └── app.js              # 业务逻辑：渲染、拖拽、PDF 导出、自动保存
├── vendor/                 # 第三方库（本地存放，离线可用）
│   ├── html2canvas.min.js  #   把简历渲染成图片
│   └── jspdf.umd.min.js    #   把图片拼成 PDF
├── tools/
│   └── build-single.js     # 打包脚本：多文件 → 单文件 HTML
├── dist/                   # 构建产物（已被 .gitignore 忽略）
└── README.md
```

**加载顺序**：`data.js` 必须先于 `app.js`（`app.js` 依赖 `data.js` 里的 `data`、`defaultSpacing` 等）。

## 功能

| 功能 | 说明 |
|---|---|
| 实时预览 | 右侧改字，左侧立即刷新 |
| 拖拽排序 | 直接拖动板块 / 公司 / 项目 / 条目调整顺序 |
| 字号配置 | 按元素类别（姓名、章节标题、正文…）分别设置 |
| 间距配置 | 全局默认值 + **每行**独立上下间距微调（只在全局基础上叠加，不影响其他行） |
| 公司 Logo | 每家公司可配 Logo 及高度 / 宽度 / 与名称的间距 |
| 引用样式 | 公司概述、项目描述可单独开关左侧引用线并选颜色 |
| 强制换页 | 可让指定公司从新一页开始 |
| 分页参考线 | 按 A4 比例显示分页位置，与导出结果一致 |
| PDF 导出 | 按预览的排版逐页截图生成，**所见即所得** |
| 自动保存 | 编辑即存入浏览器 localStorage，刷新不丢 |
| 面板折叠 | 字号 / 间距 / 内容编辑三块可展开收起 |

## 数据与存储

- 简历内容以 JS 对象形式放在 `js/data.js`，是**唯一数据源**。
- 你在页面上的所有编辑都存在浏览器 **localStorage**（键：`resume_chenpeisheng_v1`），**不写入文件**。
  - 换浏览器 / 清缓存会丢失，想长期保存请导出 PDF。
  - 想恢复内置初始数据：点预览区右上角「重置为初始数据」。

---

## 构建单文件版

```bash
node tools/build-single.js
```

脚本会依次把 `css/style.css`、两个 vendor 库、`js/data.js`、`js/app.js` 内联进 `index.html`，输出到 `dist/简历编辑器-单文件.html`。

> 不要手改 `dist/` 下的产物，每次构建都会覆盖。

---

## 注意事项

- PDF 是**图片型**（截图拼接）：优点是版式 100% 与预览一致；缺点是文字不可选中、体积较大。
- 两个 vendor 库已本地化，无需联网。
- `js/data.js` 内含个人简历信息，若仓库设为公开，请注意隐私风险。
